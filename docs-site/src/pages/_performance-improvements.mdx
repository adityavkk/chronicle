  <ul>
    <li><strong>Bounded catch-up removes whole-suffix reads and buffering.</strong> Redis fetches one frame, then optionally bulk-fetches only the range that fits the remaining 1 MiB target. A separate 1,024-frame cap bounds small-frame pages. Chronicle writes each frame directly to the socket.</li>
    <li><strong>The local 128-reader failure became a complete run.</strong> The old server completed none of the 128 accepted 16 MiB replays. The paged server completed all 128 with no server errors.</li>
    <li><strong>Horizontal scaling separates subscription work by Redis slot.</strong> The measured append fanout p99 stayed between 12.48 and 12.61 milliseconds from 1 to 8 replicas. The exact 12 replica point and a cloud run with multiple shards remain open.</li>
    <li><strong>Correctness remains a release gate.</strong> A throughput gain does not excuse a Durable Streams conformance, Jepsen, or Porcupine regression.</li>
  </ul>

<section class="block" id="evidence">
  <SectionHead num="02" label="Evidence" title="Every result needs <em>four checks</em>" />

  A performance result belongs here when the evidence names the mechanism and
  the test setup. The same record must state the correctness result and the
  remaining limit.

  <Table>
    | Check | Required evidence |
    | --- | --- |
    | Mechanism | A counter, trace, or profile that measures the repeated or serialized work |
    | System result | Throughput, latency, errors, memory, and the exact workload shape |
    | Correctness | Durable Streams conformance plus the relevant Jepsen or Porcupine scenario |
    | Limit | The next bottleneck, unmeasured configuration, or cost introduced by the change |
  </Table>

  <Callout icon="alert" label="Release rule">
    The complete Durable Streams conformance suite remains a merge blocker.
    The Jepsen and Porcupine suites remain maintained blockers. Performance
    work may change how Chronicle shares, pages, or schedules work. It must not
    weaken producer fencing, append atomicity, offsets, closure, expiry, forks,
    or persistence.
  </Callout>
</section>
